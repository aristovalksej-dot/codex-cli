# Codex CLI

**Полноценный AI-агент для работы на VDS прямо из терминала.**

Codex CLI — это мощный инструмент командной строки, который использует AI (через API codex.sale) для выполнения задач на вашем сервере: написание кода, управление файлами, работа с Git, просмотр веб-страниц и многое другое.

## Возможности

- **Файловые операции** — чтение, запись, редактирование, удаление, создание файлов и директорий
- **Shell команды** — выполнение любых команд в терминале
- **Веб-браузинг** — просмотр и парсинг веб-страниц, поиск в интернете
- **GitHub интеграция** — клонирование репо, просмотр информации, поиск, git операции
- **Анализ кода** — структура проекта, подсчёт строк, определение языков
- **Генерация кода** — создание кода на любом языке по описанию
- **Поиск** — regex поиск по файлам (grep/ripgrep), поиск файлов по имени
- **Автономный режим** — агент сам выбирает и выполняет нужные инструменты

## Установка

```bash
# Из репозитория
git clone https://github.com/aristovalksej-dot/codex-cli.git
cd codex-cli
pip install -e .

# Или напрямую
pip install git+https://github.com/aristovalksej-dot/codex-cli.git
```

## Настройка

### Быстрый старт

```bash
# Интерактивная настройка
codex --setup

# Или через переменную окружения
export CODEX_API_KEY="ваш-ключ-от-codex.sale"
codex
```

### Конфигурационный файл

Файл `~/.codex-cli/config.yaml`:

```yaml
api_key: "ваш-api-ключ"
base_url: "https://codex.sale/v1"
model: "gpt-5.3-codex"
max_tokens: 16384
temperature: 0.2
auto_approve: false
```

## Использование

### Интерактивный режим (REPL)

```bash
codex
```

### One-shot команда

```bash
codex "создай файл hello.py с функцией приветствия"
codex "покажи все Python файлы в текущей директории"
codex "установи nginx и настрой его"
```

### Флаги

```bash
codex -m gpt-5.4          # Выбрать модель
codex --auto-approve       # Автоматически одобрять все действия
codex --api-key KEY        # Указать API ключ
```

### Команды в REPL

| Команда | Описание |
|---------|----------|
| `/help` | Показать все команды |
| `/model [name]` | Переключить модель |
| `/clear` | Очистить историю разговора |
| `/config` | Показать текущую конфигурацию |
| `/tools` | Список доступных инструментов |
| `/auto` | Переключить авто-одобрение |
| `/cd <path>` | Сменить рабочую директорию |
| `/save` | Сохранить конфигурацию |
| `/exit` | Выйти |

## Доступные инструменты (19 шт.)

### Файлы
- `read_file` — Чтение файлов с нумерацией строк
- `write_file` — Создание и запись файлов
- `edit_file` — Редактирование (поиск и замена)
- `append_file` — Добавление в конец файла
- `delete_file` — Удаление файлов и директорий
- `create_directory` — Создание директорий
- `list_directory` — Просмотр содержимого директории
- `tree` — Дерево файлов

### Система
- `run_command` — Выполнение shell команд
- `grep_search` — Поиск по содержимому файлов (regex)
- `find_files` — Поиск файлов по имени

### Веб
- `fetch_webpage` — Загрузка и чтение веб-страниц
- `search_web` — Поиск в интернете (DuckDuckGo)

### GitHub / Git
- `clone_repo` — Клонирование репозиториев
- `git_command` — Любые git команды
- `github_repo_info` — Информация о репозитории
- `github_search` — Поиск по GitHub

### Код
- `analyze_code` — Анализ структуры кода
- `generate_code` — Генерация кода по описанию
